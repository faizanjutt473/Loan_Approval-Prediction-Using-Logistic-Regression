    # Loan Approval Prediction Using Logistic Regression

    ## About
    This project predicts whether a loan will be approved or not using Logistic Regression.
    Built with Python, Scikit-learn, FastAPI for deployment, and Seaborn for visualization.

    ## Features
    - Data cleaning and EDA with Seaborn
    - Logistic Regression model training
    - FastAPI API for predictions
    - 85%+ Accuracy on test data

    ## Tech Stack
    `Python` `Pandas` `Scikit-learn` `FastAPI` `Seaborn` `Matplotlib`

    ## How to Run
    ```bash
    pip install -r requirements.txt
    python train.py
    uvicorn main:app --reload
